# Грабли: ошибки, из-за которых были баги

Коротко: что было → к чему привело → как теперь. Читать перед правкой соответствующего слоя. Новый баг — новая строка в своём разделе.

## Состояние и данные

- **Две переменные на один смысл** (`liked` и `rating`) → тап менял одно, сердечко горело от другого → один источник правды — `rating`.
- **Сохранённый id, которого нет в мок-базе** → чёрный экран при каждом запуске → `cleanSaved` при загрузке, `ErrorBoundary`.
- **Картинка обоев в `localStorage`** → квота, переставало сохраняться всё → пережимать (`shrinkImage`), крупное не хранить.
- **Состояние, прочитанное до объявления** → Babel прятал ошибку, собранная версия падала → объявлять до использования.
- **Тикающий прогресс в общем контексте** → каждую секунду перерисовывалось всё дерево → отдельное хранилище (`useProgress`).
- **Пустая очередь** → деление на ноль, вместо трека `undefined`, падение → пустая очередь — кнопки ничего не делают.
- **«Далее» от начала очереди, а не от текущего трека; один шаг прогресса на все треки** → не тот следующий трек, часы шли примерно вдвое медленнее → `upNext`, шаг — секунда трека.
- **Доля, посчитанная заранее для $5** → «от вас $1,90» при любой сумме → `shareOf(artistId, monthly)`.
- **Своё правило ввода суммы в каждом поле** → «2,5» превращалось в $25 → одно `cleanAmount`.
- **Больше 13 цифр в сумме** → JavaScript теряет копейки: на экране 100…0,00 вместо 99…9,99, а с 22 цифр — «1e+22» → в поле не больше 13 цифр до запятой (граница точности, не потолок суммы).
- **Цена точки из ряда с последним значением** ($100) → у крупных сумм полосы не помещались и обрезались → сверх ряда — деление самой крупной доли на число точек в колонке.
- **Баланс из мок-базы, который не меняется** → после пополнения снова предлагалось пополнить, уведомление писало «на балансе 3,40» → баланс в состоянии (`useMoney`): пополнение и донат меняют его и пишут историю.
- **`$` прямо в строках и разметке** → выбор валюты ничего не менял → суммы только через `app.money`.
- **Импорт темы без проверки** → в настройки попадало что угодно → `cleanSettings`.
- **Плюсик альбома брал первый трек** вместо всего списка → в плейлист попадал один трек.
- **Состояние окна жило между открытиями** → мелькало прошлое «Спасибо», старый таймер закрывал новое окно → окно монтируется заново при каждом открытии.
- **Переход на текущую страницу** → дубль в истории, «Назад» загоралась впустую → «уже здесь» — только прокрутка наверх.
- **Уходящее окно читало содержимое из `app`** → там уже пусто: в тексте «NaN», Enter в поле ронял создание плейлиста → содержимое — из значения, сохранённого `useExit`, действия во время ухода не выполняются.
- **Число и слово «треков» без склонения** (`${n} треков`, «6 плейлисты») → «1 треков», «2 треков» в своих плейлистах → `t.tracksN(n)` / `t.nTracks(n)`, `playlistsN`, `followsN`.

## Жесты и события

- **Дрожание пальца считалось движением** → оценка ставилась сама → порог `SLOP` = 10 px.
- **Клик при отпускании после долгого нажатия** → нажимался пункт меню под пальцем → гасить клик глобально (`swallowReleaseClick`).
- **Тонкая полоса перемотки в капсуле** → перехватывала свайпы → в капсуле только индикатор.
- **Расчёт на всплывающий `click`** → после сдвига раскладки клик уходил соседу → поверхность сама распознаёт тап.
- **React `stopPropagation` гасит и нативное всплытие** → «клик мимо» не срабатывал → слушать `window` в фазе перехвата.
- **События портала всплывают по дереву React** → родители окна реагировали на клики внутри него → граница событий на корне портала.
- **Esc без перехвата** → вместе с окном сворачивался полный экран → `useEscape`.
- **Сочетание клавиш по `e.key`** → ⌘K не работал в русской раскладке → `e.code`.
- **Поле ввода меняло место в дереве при наборе** → после первой буквы пропадал фокус, закрывалась клавиатура → поле на одном месте в любом состоянии.
- **Окно, которое закрывается само** → не давало поправить оценку → закрытие только действием человека.
- **Свайп трека: лента шла за пальцем на 0,45 вместе с кнопками и возвращалась назад** → новый трек въезжал с той же стороны, куда ушёл старый, кнопки бледнели — «топорно и жёстко» → лента `[пред | текущий | след]` 1:1, доезжает в сторону свайпа со скоростью пальца, кнопки на месте.
- **`animation: none` перед жестом** → после жеста окно не играло уход: инлайн-«none» сильнее класса `is-out` → `finishAnims(el)` — доиграть появление.
- **Замер окна от нажатой кнопки** → кнопка сжата `:active`, окно оценки и меню вставали на пиксель ниже → `boxOf(кнопка)`.

## Слои и вёрстка

- **Класс состояния совпал с глобальным** (`pop`) → кнопка стала «квадратиком» и сдвинулась → префикс `is-*`.
- **`position: fixed` внутри элемента с `transform`** (в том числе после анимации с `fill-mode: both`) → позиция считалась от него → портал.
- **Окно внутри страницы** → затемнение не накрывало плеер и правую панель → общий `Sheet`, портал в `body`.
- **Анимация с `fill-mode: both` перебивает inline `transform`** → жест не двигал элемент → снимать анимацию перед жестом.
- **Конец анимации — по событию той, что выключается в «Уменьшить движение»** (подпрыгивание сердца, `animation: none`) → `animationend` не приходит, состояние «только что лайкнули» залипает → снимать по анимации на токенах (разлёт точек: `--t-3` в этом режиме 1 мс).
- **Inline-стиль сильнее media- и container-правил** → ступени скрытия не работали → `!important` в ступенях, inline не задавать то, чем управляет CSS.
- **Поповер, смонтированный заранее** → замер позиции шёл не вовремя → монтировать при открытии.
- **Компонент, объявленный внутри рендера** → перемонтировался и мигал → только верхний уровень модуля.
- **Контейнер тостов `left: 50%` + `translateX(-50%)`** → ширина — половина экрана, переносы → контейнер во всю ширину.
- **Ширина полосы не кратна шагу** → обрезанная половинка точки → целое число шагов.
- **Цена точки, посчитанная под 1440 px** → на других ширинах полосы обрезались, суммы выглядели одинаково → считать по ширине колонки.
- **Размер обложки полного экрана — от высоты окна (`100dvh - 400px`), без места под название** → без текста песни название ложилось на таймкод и кнопки (на любой ширине), на узком окне inline `display: flex` перебивал «спрятать обложку» и текст песни сжимался в ноль, нижний ряд уезжал за край → сцена — size-контейнер, обложка от её размеров, раскладка — классами, нижний ряд — ступенями.
- **Крупное число своим кодом с фиксированным шрифтом** (виджет на главной) → сумма вылезала за край, хотя на «Артистам» уже вписывалась → общий `useFitScale`.
- **Ширина под сумму «на глаз»** (столбцы 40 и 60 px, бейдж в одну строку с подписью) → длинная сумма вылезала и давала прокрутку вбок → столбец по самой длинной сумме, на телефоне — перенос строкой ниже, бейдж переносится.
- **Порог скрытия на глаз** → «FLAC» пропадал там, где место было → ступени подбирать замером.
- **Цвет кнопок поверх затемнённой обложки — из темы** → в светлых темах их почти не видно → поверх обложки — всегда светлые.
- **Doto** → кривое двоеточие при толщине 900, нет кириллицы → `ROND 100`, двоеточие своими точками.
- **Обводка крошечного круга толще его самого** (значок «⋯», `r=0.5`, обводка 3,4) → на телефоне точки рисовались кольцами «ooo» → точки — заливкой.
- **Черта у «назад» и «вперёд» — тонкой обводкой у заливного значка** → черты не было видно, кнопки читались как play → черта тоже заливкой.
- **Правила рейла без привязки к сайдбару** (`.shell.rail .navitem`) → в узком окне центрировались пункты настроек, значок вставал над текстом → `.shell.rail .sidebar .navitem`.
- **Подсветка по наведению на телефоне** → после касания у кнопки оставался серый круг, строка — выделенной → наведение только в `@media (hover: hover)`.
- **Полупрозрачная шапка** → прокрученное просвечивало сквозь неё → шапка непрозрачная (в Slint размытия фона всё равно нет).
- **Затемнение проявлялось через `opacity`** → лист внутри него тоже был полупрозрачным, сквозь пункты меню читалась нижняя навигация → у затемнения анимируется только цвет фона (`scrimIn`/`scrimOut`).
- **Лист снизу с перелётом** (`--ease-enter`) → приподнимается над краем экрана, снизу мелькает щель → под листом «юбка» его цвета — тенью, не `::after`: `overflow` его обрезает.
- **`non-scaling-stroke` у кольца загрузки** → штрих прогресса (`dasharray`) считался бы в px экрана, а не в единицах кольца → у кольца толщина пересчитана от размера (`30 / s`), `non-scaling-stroke` — только у `Ic`.

## Рефакторинг

- **Зависимость эффекта от массива, который создаётся заново на каждый рендер** (`DB.lyricsFor`) → текст песни прокручивался каждую секунду → зависеть от простых значений.
- **Другое разбиение текста на узлы** (`{a} {b}` вместо одной строки) → буквы в подписях с разрядкой сдвигались на 1–2 px → при переносе разметки разбиение не менять.

## Выкладка и проверка

- **Файлы из кэша сразу после выкладки** (GitHub Pages: `max-age=600`, обновление страницы перепроверяет только HTML) → исправленное у владельца выглядело неисправленным, смесь старых и новых скриптов роняла приложение → к адресам файлов — `?v=` со временем выкладки.
- **Загрузчик Babel считает успехом только 200** → Firefox при перепроверке кэша отвечал 304, файл молча пропускался, приложение падало на «ErrorBoundary is not defined» (экран ошибки в Firefox, в Chrome всё работало) → у `.jsx` адрес новый при каждом открытии, при «Could not load» — одна перезагрузка.
- **Проверки только с чистым кэшем** (новый профиль на каждый тест) → сбой, который бывает лишь при повторной загрузке с кэшем, не ловился → гонять и повторные загрузки в одном профиле, на живом демо.
- **Проверка только в Chromium** → то, что владелец ловил в Яндекс Браузере и Firefox, не воспроизводилось → проверять в трёх браузерах (раздел 9 брифа).
- **Живая сборка отдельными файлами** (`files`: `css/app.css`, `js/*.js`) → в Claude Code на телефоне не работала; без соседних файлов страница — пустой белый экран, а проверял я её только с обычной раздачей → одним файлом (раздел 8 брифа) и ещё проверка «только страницей» (`page.setContent`).
- **Firefox без экрана (headless) — `(hover: none)`** → прототип принимал его за сенсорный: правый клик не открывал меню, наведения нет → это среда, а не баг; в проверках — `ui.primaryPointerCapabilities` и `ui.allPointerCapabilities` = `6` (точный указатель и наведение).
- **Касание в тесте попало под мини-плеер** (третья строка альбома на 412 px) → долгое нажатие «не работало» → касаться только видимых строк.
- **Тест перезагружал страницу сразу после `load`** → Babel собирает приложение уже после `load`, шрифты только начинали качаться, и Firefox писал в консоль «downloadable font: download failed» (`NS_BINDING_ABORTED`) — ошибка теста, не прототипа → перед перезагрузкой ждать отрисовки (`.shell`, `.ob`) и `document.fonts.ready`.
