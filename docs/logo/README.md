# Логотип Spotless

Знак — **«волна голосового»**: столбики разной высоты, как дорожка записи, а вместо одного столбика — красная точка. Цвета — из палитры «Точка»: `#F2F2F2`, `#D71921`, `#000`. Надпись SPOTLESS собрана из точек, как цифры в интерфейсе; в «O» — та же красная точка. Всё нарисовано фигурами, без шрифтов.

| Файл | Что это |
|---|---|
| `spotless-icon.svg` | значок: чёрная скруглённая плитка |
| `spotless-icon-round.svg` | значок в круге |
| `spotless-icon-square.svg` | значок на чёрном квадрате |
| `spotless-mark.svg` / `spotless-mark-dark.svg` | только знак, без фона — для тёмного / светлого фона |
| `spotless-logo.svg` / `spotless-logo-dark.svg` | знак с надписью, без фона — для тёмного / светлого фона |
| `github-social-preview.png` | картинка-превью репозитория, 1280×640 |

В прототипе логотип пока не используется.

## Запасные значки (`reserve/`)

Точечная синусоида, линия с плейхедом и точечная волна. Хранятся на будущее: если приложение когда-нибудь станет известным, пользователи смогут выбирать себе значок. **До тех пор выбор значка в приложении не давать** — ни в прототипе, ни в настройках.
